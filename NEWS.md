# AKsf 0.1.0

- Documentation code now has keyboard-accessible show/hide panels, with rendered guides and a source-code catalogue; printed results remain visible.

- Initial Alaska R mapping package inspired by nzsf.
- Bundled NOAA/NMFS reporting areas and ADF&G groundfish statistical and registration areas.
- Six NPFMC FMPs represented by eight documented reference polygons.
- Explicit crab/groundfish boundary distinction, separate Cook Inlet salmon area,
  and opt-in international reporting area 550.
- Dateline-safe default projection, composable map layers, provenance manifest,
  reproducible data builds, offline tests, and cross-platform CI.

- Added AFSC ecosystem integration guide covering coldpool, akgfmaps, and navmaps,
  with explicit redundancy, complementary capabilities, and optional examples.

- Added GMT/OGR polygon export with hole and dateline tests, a GMT tutorial,
  and pkgdown/GitHub Pages site configuration.

- Added NOAA spatial-closures vignette, source catalog, and a provenance-tracked
  two-record historical GOA habitat example with mapping and GMT export.
